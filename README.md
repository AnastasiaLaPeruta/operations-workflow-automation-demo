Operations Workflow Automation Demo

Overview

This project demonstrates a simple Python-based workflow for automating operational spreadsheet cleanup and reporting tasks.

The workflow:

* Cleans intake spreadsheet data
* Standardizes names, emails, and statuses
* Removes duplicate records
* Generates a revenue summary report

Technologies Used

* Python
* Pandas

Files

* messy_intake_data.csv
* automation_demo.py
* cleaned_data.csv (generated after running)
* revenue_summary.csv (generated after running)

Example Use Cases

* Insurance intake cleanup
* Healthcare operations reporting
* Legal client intake normalization
* Recruiting pipeline cleanup

Value

This type of workflow can help reduce repetitive spreadsheet cleanup work and improve consistency in operational reporting processes.
